1. Інструкція ISA
Опкод	Мнемоніка	Розмір	Прапорці	Що робить	
0x10	ADD A, B	1	    Z N C	    A = A + B	
0x11	SUB A, B	1	    Z N C	    A = A - B	
0x12	AND A, B	1	    Z N, C=0	A = A & B	
0x13	OR A, B	    1	    Z N, C=0	A = A | B	
0x14	XOR A, B	1	    Z N, C=0	A = A ^ B	
0x15	NOT A	    1	    Z N, C=0	A = ~A	
0x16	SHL A	    1	    Z N C	    A = A << 1; у C потрапляє біт, що виїхав із сьомої позиції	
0x17	SHR A	    1	    Z N C	    A = A >> 1; у C потрапляє біт, що виїхав із нульової	
0x18	INC A	    1	    Z N	        A = A + 1	
0x19	DEC A	    1	    Z N	        A = A - 1	
0x1A	CMP A, B	1	    Z N C	    порахувати A - B, виставити прапорці, результат викинути	
0x1B	MUL A, B	1	    Z N C	    A = A * B, молодші 8 бітів; C виставляється, якщо справжній добуток не вліз	

Додатково:
0x00	HALT	        1	—	зупинитись; наступні step відмовляють	
0x01	NOP	            1	—	нічого	
0x02	OUT	            1	—	надрукувати A як символ	
0x03	OUTN	        1	—	надрукувати A як десяткове число і пробіл	
0x04	OUTS addr16	    3	—	друкувати байти з addr, поки не трапиться 0 або поки не набереться 256 байтів

2. Приклади роботи ALU
1)
ember> reg a 200 - задаємо першому значенню 200
ember> reg b 100 - задаємо другому значенню 100
ember> set 0 0x10 - 0x10	ADD A, B
ember> regs - стан регістрів
PC:0 A:200 B:100 Z:0 N:0 C:0 
ember> step - виконуємо інструкцію ADD
ember> regs - стан регістрів
PC:1 A:44 B:100 Z:0 N:0 C:1 - після додавання вийшло: A=44 (тому що, переповнення 200+100=300, 300-256=44). PC - наступна адреса команди, C - переповнення 8 біт.

2)
ember> reg a 100 - задаємо першому значенню 100
ember> reg b 200 - задаємо другому значенню 200
ember> set 1 0x11 - 0x11    SUB A, B
ember> regs - стан регістрів
PC:1 A:100 B:200 Z:0 N:0 C:1 
ember> step - виконуємо сет
ember> regs - стан
PC:2 A:156 B:200 Z:0 N:1 C:1 - після віднімання вийшло А = 156 (100-200=-100, 256-100=156). Флаг N=1, бо результат від`ємний

PC:3 A:0 B:0 Z:1 N:0 C:1
